週数別 2D/4D 早見表 / Week-by-Week Guide

2Dは医学的な発育・構造チェック(生存確認・臓器スクリーニング・計測)が役割、4Dは立体的な表情・仕草を捉えてボンディング(愛着形成)を促す役割です。日付を入力すると、該当する週の行がハイライトされます。
2D = medical structural check. 4D = bonding via 3D facial expressions. The matching row highlights once you enter a date above.
週数 2Dで確認できること・役割 4Dの見え方・役割 4D鮮明度
心拍確認について: 2Dエコー(経腟)では妊娠5週後半〜6週前半頃から胎芽の心拍拍動が確認できます。初期は「拍動の有無」のみですが、中期以降は心拍数(正常110〜160bpm)や心臓の4つの部屋の構造まで確認する、生存・発育判定の最重要ツールです。
Heart rate can be seen via 2D transvaginal scan from ~5.5–6 weeks. Early on it's presence/absence only; later it includes rate (110–160bpm) and 4-chamber structure — the core tool for viability checks.
